# Zellij SupaTheme Theme

1. Identify the active config directory with `zellij setup --check`.
2. Create its `themes` subdirectory and copy `SupaTheme.kdl` there.
3. Add the root-level setting `theme "SupaTheme"` to that directory's `config.kdl`.

Alternatively, launch Zellij with `zellij options --theme SupaTheme`.
